Questions and answers

Is this PDF editor really free?

Yes. There is no sign-up, no watermark and no limit on files or pages.

Is my PDF uploaded to a server?

No. The PDF is opened, edited and saved by your own browser. It never leaves your computer, so it is safe for private documents such as contracts, invoices and forms.

Can I edit the existing text in a PDF?

Yes. Choose Edit text and click on any text. The editor reuses the font, size and color from the PDF, so your change looks like the original.

What else can I do?

Add new text, images and signatures, draw, highlight, hide parts with white-out, and rotate, reorder, add, merge or delete pages. Then download the edited PDF.

Does it work on Mac, Windows and Linux?

Yes. It works in any modern browser, such as Chrome, Edge, Firefox and Safari. Nothing needs to be installed.
